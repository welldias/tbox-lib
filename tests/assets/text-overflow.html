text-overflow and line-clamp

text-overflow: ellipsis and strings

ellipsis: a text far too long to fit in this box

string " [...]": a text far too long to fit here

string "~": a text far too long to fit in this box

two values, the end one applies: text far too long to fit

line-clamp

No limit: this long paragraph goes on for several lines without any cut, showing all the text up to the end of the sentence.
-webkit-line-clamp: 2 cuts this long paragraph at the second line and ends with an ellipsis in place of the rest of the text.
line-clamp: 3 shows up to three lines of this sample text, which is long on purpose to go past the configured limit.
a single line with an ellipsis at the end of the text

It also works on a paragraph: a two-line limit applied to the p element inside the card.
